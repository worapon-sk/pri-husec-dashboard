# ศรส. Dashboard จังหวัดปราจีนบุรี

ระบบ Dashboard สำหรับติดตามและแสดงสถิติภาพรวมการทำงานของศูนย์ช่วยเหลือสังคม (ศรส.) จังหวัดปราจีนบุรี

## ภาพรวม

เว็บไซต์นี้เป็นแผงควบคุมแบบรายงานสถิติที่ช่วยให้ผู้ดูแลสามารถติดตามสถานะเคส การกระจายตามอำเภอ ประเภทเหตุการณ์ และกลุ่มเป้าหมายได้แบบเรียลไทม์ โดยใช้ข้อมูลจาก Google Apps Script Web App และแสดงผลผ่านหน้าเว็บแบบ responsive

## คุณสมบัติ

- แสดงสถิติภาพรวมในรูปแบบ KPI Cards
- กราฟสรุปสถานะเคสแบบ Doughnut/Bar/Pie
- แสดงรายชื่อเคสล่าสุดและรายการเคสทั้งหมด
- คัดกรองข้อมูลตามอำเภอและช่วงเวลา
- ดูข้อมูลแยกตาม 7 อำเภอของจังหวัดปราจีนบุรี
- มีโหมด Dark Mode
- รองรับการแสดงผลบนอุปกรณ์ต่าง ๆ
- สีและการออกแบบแบบ admin dashboard

## เทคโนโลยีที่ใช้

- HTML5
- Tailwind CSS (CDN)
- Chart.js
- Font Awesome
- JavaScript
- Google Apps Script (สำหรับดึงข้อมูลจาก Sheet/API)

## โครงสร้างโปรเจกต์

```text
.
├── index.html              # หน้า Dashboard หลัก
├── src/
│   ├── Form.html           # หน้า/ฟอร์มสำหรับข้อมูลที่เกี่ยวข้องกับระบบ
│   └── Code.gs             # โค้ด Google Apps Script (ถ้าตั้งค่าใช้งาน)
├── README.md               # เอกสารคู่มือโปรเจกต์
└── .gitignore              # หากมีการตั้งค่าเพิ่มเติม
```

## วิธีใช้งาน

### 1. Clone โปรเจกต์

```bash
git clone https://github.com/worapon-sk/pri-husec-dashboard.git
cd pri-husec-dashboard
```

### 2. เปิดหน้าเว็บ

สามารถเปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ได้ทันที หรือ deploy บน GitHub Pages / static hosting อื่น ๆ

### 3. ตั้งค่า API

ไฟล์ `index.html` มีค่าตัวแปรต่อไปนี้:

```javascript
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/.../exec";
```

ให้แทนค่า URL ของ Google Apps Script Web App ที่คุณได้ deploy ไว้ เพื่อให้ระบบเรียกข้อมูลเคสจากฐานข้อมูลหรือ Google Sheet ได้

## คุณลักษณะของข้อมูล

Dashboard นี้ใช้ข้อมูลสถิติจากเคสต่าง ๆ เช่น:

- รหัสเคส
- วันที่รับแจ้ง
- อำเภอ
- ความสำคัญ / ระดับความเร่งด่วน
- สถานะเคส
- เหตุการณ์/ประเภทปัญหา
- กลุ่มเป้าหมาย

## ตัวอย่างข้อมูล JSON

ข้อมูลที่ API ควรส่งกลับมีรูปแบบประมาณนี้:

```json
{
  "cases": [
    {
      "caseId": "PR-001",
      "date": "2026-01-15",
      "district": "เมืองปราจีนบุรี",
      "status": "รับแจ้ง",
      "priority": "ด่วนที่สุด",
      "criticalType": "ข่มขู่/ทำร้ายร่างกาย",
      "targetGroup": "สตรี"
    }
  ]
}
```

## Deployment

### GitHub Pages

1. เปิด Repository Settings
2. ไปที่ Pages
3. เลือก Source เป็น GitHub Actions หรือ Branch ที่เป็น static site
4. เผยแพร่เว็บไซต์

## ข้อควรทราบ

- โปรเจกต์นี้เป็นหน้าเว็บแบบ Static Front-end และขึ้นกับข้อมูลจากแหล่งภายนอก
- หากยังไม่ได้กำหนด Google Apps Script URL หรือ API ไม่ตอบสนอง ระบบอาจแสดงผลเป็นค่า 0 หรือไม่แสดงข้อมูล
- สำหรับข้อมูลที่เป็นข้อมูลภายใน/ส่วนบุคคล ควรตรวจสอบนโยบายความเป็นส่วนตัวและการคุ้มครองข้อมูลตาม PDPA ให้ครบถ้วนก่อนเผยแพร่ทางสาธารณะ
